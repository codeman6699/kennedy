# Ineza Kennedy — Developer Portfolio

A responsive Vue 3 + Vite developer portfolio built with reusable Vue components and Lucide Vue Next icons.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Project structure
```text
src/
  assets/kennedy-mark.svg
  components/
    AboutSection.vue
    AiAssistant.vue

    HeroSection.vue

    ProjectsSection.vue

    SiteHeader.vue
    SkillsSection.vue

  main.js
  style.css
```

## Personalise before publishing
- Add a verified professional email address and any public contact details.
- Replace GitHub profile links with individual repository/demo URLs when confirmed.
- Add verified education, work history, certificates and a formal CV if you want them shown.
- The project stages are intentionally described as concepts or in development, not as completed client work.

## AI assistant
The portfolio assistant is a local, context-based guide that answers common questions using the profile and project information included in this site. It does not call an external AI model or require an API key. A live AI service can be connected later through a secure backend.

## Contact form
The contact form validates the required fields and copies the enquiry to the visitor's clipboard. It does not send or store the message. Connect a verified email endpoint or backend before advertising it as a live message service.
